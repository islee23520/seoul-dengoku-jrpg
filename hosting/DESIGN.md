# Web player host

The host preserves the existing OPRN runtime rather than reskinning it.
Public entry is a separate map-preview consent screen, never production start.

Tokens: night #05070c, ink #e9ecf3, secondary #b6bece from runtime dark
tokens; neutral hairline rgba(255,255,255,.17). System sans text, monospace
eyebrow, body 17px, heading clamp(28px,5vw,48px). Spacing 8/16/24/32px.
Reading measure 48rem, page inset 24px, minimum target 44px.

Primitives: document main, eyebrow, heading, explanatory paragraph, primary
navigation link, native details credits. Focus-visible uses ink outline;
links underline on hover. No animation, card stripes, or decorative imagery.
One document scroll owner; runtime owns its existing viewport separately.
System light/dark does not change the deliberately dark game canvas.

## Campaign map (Unity R4 port, task12)

Source: StrategyMapScreen flat route (BuildWorldControls, BuildPersonHud) and
FoundationPovHud. Geometry is `game/data/campaign/map-view.json`, generated by
`scripts/tools/campaign-map-view.mjs` from the task2 atlas (hash-bound); rank
boundaries are outlines drawn from the dong topology; title membership is the
atlas's own (county currentSlots, countyIds above), so duchies can overlap.

Layout: campaign-map - full-bleed SVG map under a 48px common navigation, 303px identity dock at x16, 303px state-control dock at x331, 303px titles/holdings dock at the right margin (1280x720); scroll owner: none at 1280, the right dock's detail list scrolls on its own; anti-patterns: omniscient labels/colours outside scope, review route strip, enabling the unported settings/POV-off controls. At 1000px and below the docks stack under the map and the document scrolls (not Unity parity).

Primary action: select a held title / holding / dong. Priorities: the lord and
scope (left), the map with jurisdiction, the selection context (right).
Required content: 이서담, 양천 구역장, 소속국 수문국, 현재 위치, 직속 주군 한재목,
국가 통제, 보유 작위 양천구 공작령, 직접 보유 영지 양천구, 관할 지역 18 and its 18
dong, 신정2동 주민센터, header mode controls 정치/작위/남작령-제국/철도, 무주지 legend.
Scope: an interim rule chosen by task12 (the plan does not define it) until
tasks 4/10 deliver report-based knowledge: only the 18 dong of the admitted K002
holding are known; every other region is drawn without colour or label and
cannot be selected. Portraits: Unity has no registered texture for K002/K568/K616, so its own
fallback (empty 80/40px area with the user icon) is shown. Left out: map
legend panel and zoom buttons (not in R4; wheel, drag and +/-/0 keys zoom),
settings panel
(disabled, as in the menu), POV-off (would be omniscient).

Accessibility: native landmarks/links, explicit preview limitations, readable
wrapping, keyboard operation. Existing runtime accessibility/mobile limitations
are inherited, not silently represented as new approval. No new game rules.
